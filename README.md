# ollaya Decision Model Lab

olllaya 레지스트리 전체 결정모델(11 패밀리 21 모델) × 질문 유형(choice/score/noul) 통합 테스트 웹앱.

- 배포: https://ollaya-lab.dydtnsp.workers.dev
- 서버: 노트북 ollllaya daemon (tailnet) — 접속 정보는 UI에서 입력(서버 URL + OLLAYA_API_KEY)
- 기능: 레지스트리 카탈록(설치 상태 런타임 갱신), 모델별 임베디드 프리셋 질문셋, 질문 JSON 편집, /api/decide 결과(확률 바·라우팅·타이밍) 시각화
- 시각언어: ollllaya 앰버(#f0b429) 컨셉 — laya PWA(초록)와 명시 차별
